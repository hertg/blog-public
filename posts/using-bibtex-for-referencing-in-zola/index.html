Using BibTeX for referencing in Zola

Presenting a better alternative to reference sources on a static page generated with Zola. With a single BibTeX file, auto numbering, and the possibility to easily add in-text references.

December 13, 2023
7 minutes
Michael Hertig
Updated on December 19, 2023
dev guide

Introduction

If you are anything like me, you may not particularly like the Footnotes feature, as it is available in Markdown. There are also some unresolved issues [1] [2] in Zola, and the Markdown footnotes have just never really satisfied my needs.

In this guide, I present an alternative where we can use a simple BibTeX file to put all our references and then cite them in text with an easy-to-use shortcode.

Our Goal

We want to have a single references.bib file that contains all of our references. This file can simply be added as a co-located asset to the markdown file.

content/
  my-blog-post/
    index.md 
    references.bib

Our references.bib file may look like this:

@misc{danielmolina,
  title = "Automatic list of papers using Zola and Bibtex",
  url = "https://www.danimolina.net/en/posts/bibtex-papers/",
  author = "Daniel Molina",
  year = 2023,
  month = 8,
}

And our markdown file may contain the following text.

One blog post {{ reference(key="danielmolina") }} 
has been particularly helpful in the creation of 
this guide.

As you can see, this guide will enable you to collect all your references in a single file and then use them for in-text citations with a simple shortcode [5] . The result can be observed in this very blog post.

Loading the co-located BibTeX file

In your Zola template, add the following piece of code at the position where you'd like the references to show up; In my case, I've put this code right below the line where it renders the page.content.

{{ page.content | safe }}

{% set citations = load_data(path=page.colocated_path ~ "references.bib", format="bibtex", required=false) %}
{% if citations %}
    <div id="references">
    {% set has_references = citations.bibliographies | length > 0 %}
    {% if has_references %}
        <h2>References</h2>
        <dl>
        {% for citation in citations.bibliographies %}
            {{ macros::ref(bibliography=citation,num=loop.index) }}
        {% endfor %}
        </dl>
    {% endif %}
    </div>
{% endif %}

This code will check if there is a references.bib file colocated with the markdown file and load it if it exists. If the file does not exist, nothing will be loaded or rendered.

Of course, I encourage you to change this template and adapt it to your needs. The key parts of the code here are the call to the macro, which we will create next, and the use of loop.index for the num argument.

The loop.index is a variable that is automatically made available by the Tera templating engine, and it starts at 1. This means all references will be numbered from 1 and upwards in the order that they appear in the BibTeX file.

Creating the macros

The code we put in our page template calls a macro called ref; this does not yet exist, and we'll have to create it ourselves.

Don't get overwhelmed by the code below. This is by far the largest part of this guide and is also what took me the most time to implement.

If you don't have a file for your macros yet, simply create a macros.html file within the templates/ directory of your Zola page. Macros [6] are a feature of Tera [7] , the template engine used by Zola.

{% macro bibstrip(in) %}
{{ in | replace(from="---",to="—") | replace(from="--", to="-") | replace(from="{",to="") | replace(from="}", to="") | safe }}
{% endmacro bibstrip %}

{% macro bib_book(ref) %}
    {{ ref.tags.author }}, 
    <em>{{ ref.tags.title }}</em>, 
    {{ ref.tags.publisher }}, 
    {{ ref.tags.year }}
{% endmacro bib_book %}

{% macro bib_article(ref) %}
    {{ ref.tags.author }}, 
    "{{ ref.tags.title }}", 
    <em>{{ ref.tags.journal }}</em>, 
    vol. {{ ref.tags.volume }}, 
    {{ ref.tags.number}}, 
    pp. {{ ref.tags.pages }},
    {% if ref.tags.month %}{{ ref.tags.month }}{% endif %}
    {{ ref.tags.year }}
{% endmacro bib_article %}

{% macro bib_inproceedings(ref) %}
    {{ ref.tags.author }}, 
    "{{ ref.tags.title }}," 
    in <em>{{ ref.tags.booktitle }}</em>, 
    {{ ref.tags.address }},
    {{ ref.tags.year }}, 
    pp. {{ ref.tags.pages }}
{% endmacro bib_inproceedings %}

{% macro bib_manual(ref) %}
    {{ ref.tags.author }}, 
    <em>{{ ref.tags.title }}</em>,
    {{ ref.tags.organization }},
    {{ ref.tags.address }}, 
    {% if ref.tags.edition %}{{ ref.tags.edition }},{% endif %}
    {% if ref.tags.month %}{{ ref.tags.month }}{% endif %}
    {{ ref.tags.year }}.
{% endmacro bib_manual %}

{% macro bib_thesis(ref, type) %}
    {{ ref.tags.author }}, 
    "{{ ref.tags.title }}," 
    {{ type }},
    {{ ref.tags.school }},
    {{ ref.tags.address }}, 
    {{ ref.tags.year }}
{% endmacro bib_thesis %}

{% macro bib_mastersthesis(ref) %}
    {{ macros::bib_thesis(ref=ref,type="M.S. Thesis") }}
{% endmacro bib_mastersthesis %}

{% macro bib_phdthesis(ref) %}
    {{ macros::bib_thesis(ref=ref,type="Ph.D. dissertation") }}
{% endmacro bib_phdthesis %}

{% macro bib_misc(ref) %}
    {% if ref.tags.author %}{{ ref.tags.author }},{% endif %}
    {{ ref.tags.title }},
    {% if ref.tags.publisher %}{{ ref.tags.publisher }},{% endif %}
    {% if ref.tags.year %}{{ ref.tags.year }},{% endif %}
    {% if ref.tags.doi %}
        <a href="https://doi.org/{{ ref.tags.doi }}">{{ ref.tags.doi }}</a>
    {% elif ref.tags.url %}
        <a href="{{ ref.tags.url }}" target="_blank">{{ ref.tags.url }}</a>
    {% endif %}
{% endmacro bib_misc %}

{% macro bib_ref(bibliography,num) %}
    {% if bibliography.entry_type == "book" %}
        {{ macros::bib_book(ref=bibliography) }}
    {% elif bibliography.entry_type == "article" %}
        {{ macros::bib_article(ref=bibliography) }}
    {% elif bibliography.entry_type == "inproceedings" %}
        {{ macros::bib_inproceedings(ref=bibliography) }}
    {% elif bibliography.entry_type == "misc" %}
        {{ macros::bib_misc(ref=bibliography) }}
    {% elif bibliography.entry_type == "mastersthesis" %}
        {{ macros::bib_mastersthesis(ref=bibliography) }}
    {% elif bibliography.entry_type == "phdthesis" %}
        {{ macros::bib_phdthesis(ref=bibliography) }}
    {% elif bibliography.entry_type == "manual" %}
        {{ macros::bib_manual(ref=bibliography) }}
    {% elif bibliography.entry_type == "githubissue" %}
        {{ macros::bib_githubissue(ref=bibliography) }}
    {% else %}
        unsupported reference type
    {% endif %}
{% endmacro bib_ref %}

{% macro ref(bibliography,num) %}
    <dt class="ref-num" id="bibref-{{ bibliography.citation_key }}">[{{ num }}]</dt>
    <dd>{{ macros::bibstrip(in=macros::bib_ref(bibliography=bibliography,num=num)) }}</dd>
{% endmacro ref %}

I've split the code up into multiple macros to make it a little bit more digestible. Here is a rundown of the different macros.

  • macros::ref The macro we call from the template takes a single bibliography object and the reference number as an argument
  • macros::bib_ref Looks at the entry_type of the reference and subsequently calls the corresponding formatter macro for that particular reference type
  • macros::bibstrip A custom utility function that simply strips out leftover curly braces (that may be kept by the BibTeX parser to denote literal values) and converts double and triple dashes to En and Em dashes, respectively

The rest of the macros, macros::bib_book, macros::bib_article, macros::bib_inproceedings, macros::bib_manual, macros::bib_thesis, macros::bib_mastersthesis, macros::bib_phdthesis, macros::bib_misc are simply different formats for the different BibTeX entry types [8] .

The bibliography object

A bibliography object, as it is passed into the macros, looks as follows:

{
  "entry_type": "misc",
  "citation_key": "danimolina",
  "tags": {
    "title": "Automatic list of papers using Zola and Bibtex",
    "url": "https://www.danimolina.net/en/posts/bibtex-papers/",
    "author": "Daniel Molina",
    "year": "2023",
    "month": "8"
  }
}

If you'd like to debug your own bibliography while tweaking the reference formatting, you can add the following code to your page template to render it in its JSON representation:

<pre>
    {{ citations | json_encode(pretty=true) | linebreaksbr | safe }}
</pre>

A note on the formatting

Please note that the format implemented here does not adhere to any specific citation style. It is loosely based on the IEEE format [9] but simplified to make it easier to implement with Tera.

I will reference a few unrelated sources here just to showcase what the different entry types will look like in my formatting.

  • An article [10]
  • A book [11]
  • A conference paper [12]
  • A manual [13]
  • A masters thesis [14]
  • A PHD dissertation [15]
  • And an RFC [16]

If you want to achieve guideline-compliant formatting of your references, you will have to update the macros or use another way to pre-format the references before loading them into the template.

There are other ways to achieve the same
While I was working on this, a few other possibilities came to my mind for how the BibTeX could be formatted. One potential way of achieving the same would be to introduce an additional build step before the site gets built with Zola. For example, a python script or a simple CLI could be used to turn the BibTeX files into pre-formatted JSON files, and then those JSON files could get loaded into the template.

The reason I decided to go with this solution instead was that I like the way that it works fully integrated. It keeps the build as simple as any Zola page and doesn't require the installation of external tooling or dependencies. And after all, I'm just using it for blog posts, not academic papers. :)

Creating the shortcode

Notice how we gave the references in the macros::ref macro an id of bibref-{{ bibliography.citation_key }}. This was done so that we could link to the individual references from in-text citations.

Create a file at templates/shortcodes/reference.html with the following content.

{% set citations = load_data(path=page.colocated_path ~ "references.bib", format="bibtex", required=false) %}
{% if citations %}
    {% for bib in citations.bibliographies %}
        {% if bib.citation_key == key %}
            {% set_global num = loop.index %}
        {% endif %}
    {% endfor %}
    <a href="#bibref-{{ key }}" class="ref-link">[{{ num | default(value="#noref") }}]</a>
{% endif %}

This code looks very similar to what we did in the page template. It takes an argument called key and loads the co-located references.bib asset. It then loops over all the bibliography entries and sets a global variable num if the provided key matches the key of the BibTeX entry.

This means that all references will be numbered in the order that they appear in the references.bib file, starting at 1. The unfortunate drawback of this is that references are not numbered in the order that they appear in the markdown. You'll have to manually keep the order of entries the same as the order of in-text citation if that is of importance to you.

This shortcode can be used from your markdown files as follows:

{{ reference(key="somekey") }}

Where the key must match the entry key of the BibTeX reference.

@misc{somekey,
  title = "Some title",
  url = "https://www.example.org/",
  author = "John Doe",
}

Adding Stylesheets

How you want to style your references is left up to you. To get you started, you can take inspiration from the way that I chose to style the references on this page.

a.ref-link {
    font-size: 1rem;
    text-decoration: none;
}

#references {
    font-size: 0.9rem;

    dl {
        display: grid;
        overflow: hidden;
        grid-template-columns: max-content minmax(0,1fr);
        row-gap: 0.8rem;
    }

    dt {
        grid-column-start: 1;
        padding-right: 0.8rem;
    }

    dd {
        grid-column-start: 2;
        -webkit-hyphens: auto;
        -moz-hyphens: auto;
        -ms-hyphens: auto;
        hyphens: auto;
    }
}

Some caveats

  1. As already mentioned further above, this implementation does not adhere to any citation style. If you wish your references to be formatted in a specific style, you will have to adjust the macros or choose another way of pre-formatting the bibliography.
  2. The references will be numbered in the order they appear in the references.bib, not in the order they were mentioned in the Markdown.
  3. There will be no backlinks from the references back up into the in-text citations
  4. Zola may throw errors if your BibTeX contains non-numeric month fields. As a workaround, you can add the following code at the top of your references.bib file:
    @string (jan="1")
@string (feb="2")
@string (mar="3")
@string (apr="4")
@string (may="5")
@string (jun="6")
@string (jul="7")
@string (aug="8")
@string (sep="9")
@string (oct="10")
@string (nov="11")
@string (dec="12")

If you use and improve upon my macros, make sure to link back to my post and/or notify me if you do a write up on them. I am interested in the alternative solution you come up with!
