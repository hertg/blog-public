Implementing toggleable dark mode on a website

A minimalistic way to implement dark mode support on any website, respecting the browsers preferred theme, while still allowing to manually toggle between light and dark

November 12, 2023
4 minutes
Michael Hertig
dev guide

Features

Here is a list of what features and potential issues have been taken into consideration while writing this guide:

  • Minimal code required
    The amount of SLOC have been reduced to a minimum
  • Respecting the users preferences
    If the browser prefers dark mode, give them dark mode
  • Toggle
    Users can manually switch between modes
  • No cookies
    Selected mode is persisted to localStorage
  • Good UX, no FOUC
    Page will not flash white on dark mode

Adding the theme switch toggle

First, add a simple toggle element to your page. This can be anything, and you are free to switch it up to whatever you like.

In my example, I'm creating a simple <div> that will be the clickable toggle, and inside is the icon to be shown as the toggle button. This will display a feather icon of a moon to switch to dark mode, and a sun icon to switch to light mode.

<div id="dark-mode-toggle">
  <i class="light-only" data-feather="moon"></i>
  <i class="dark-only" data-feather="sun"></i>
</div>

We will later add a click listener to the #dark-mode-toggle ID and add some CSS to make .light-only only appear in light-mode, and .dark-only only in dark-mode.

Styling the toggle button

For the sake of simplicity, I'm not going to style the toggle button any further. This code simply adds a pointer cursor when hovering over the toggle button, and it will make sure that only one of the icons is shown at a time.

#dark-mode-toggle {
    cursor: pointer;
}

html[data-theme="dark"] .light-only {
    display: none;
}

html[data-theme="light"] .dark-only {
    display: none;
}

The [data-theme] attribute referenced here is a custom data attribute that we will add to the <html> element in the next step.

Load theme or use browser default

Unfortunately, a few lines of JavaScript are necessary to make this all work. The following code is just plain old JavaScript, no need for any frontend frameworks or bundlers.

var theme = localStorage.getItem("theme");
if (!theme) {
    var prefersDark = window.matchMedia("(prefers-color-scheme: dark)");
    theme = prefersDark ? "dark" : "light";
}
setTheme(theme);

function setTheme(theme) {
    localStorage.setItem("theme", theme);
    document.documentElement.setAttribute("data-theme", theme);
}

This code does the following:

  1. Check whether a theme has already been stored in localStorage
  2. If nothing is stored yet, select the default theme based on the preferences reported by the browser
  3. Store the (auto-) selected theme to localStorage and set the [data-theme] attribute on the <html> element.
Notice, how the JavaScript code runs immediately and doesn't need to wait on DOMContentLoaded or be placed at the bottom of the page. In fact, it shouldn't. A delayed execution of that code would lead to FOUC on full page navigation or refresh (e.g. the page flashing white before dark mode is applied).

This will result in your website always having the data-theme attribute automatically set on the <html> root element.

<!-- example result of the code above -->
<html data-theme="dark">

Allow to manually change the theme via toggle

The next vital step is to wait for the DOM content to be loaded and then attempt to register a click event listener on the #dark-mode-toggle element which will toggle between dark and light when clicked.

document.addEventListener("DOMContentLoaded", onLoad);

function onLoad() {
    var darkModeToggle = document.getElementById("dark-mode-toggle");
    if (darkModeToggle) {
        darkModeToggle.addEventListener("click", function (_) {
            var currentTheme = localStorage.getItem("theme");
            setTheme(currentTheme == "dark" ? "light" : "dark");
        });
    }
}

Implementing the actual themes

How to go about designing accessible dark and light themes for a website is outside the scope of this post. But the following CSS can give you an idea on where to start by using CSS variables.

:root {
    --background-color: rgb(255, 255, 255);
    --text-color: rgb(10, 10, 10);
    --anchor-color: rgb(32, 32, 255);
    --accent: rgb(255, 155, 223);
    --accent-contrast: rgb(255, 255, 255);
}

:root[data-theme="dark"] {
    --background-color: rgb(16, 16, 16);
    --text-color: rgb(230, 230, 230);
    --anchor-color: rgb(185, 185, 255);
    --accent: rgb(255, 155, 223);
    --accent-contrast: rgb(255, 255, 255);

    img {
        filter: grayscale(30%);
    }
}

Then use those variables in the styling of your website, for example:

body {
    background-color: var(--background-color);
    color: var(--text-color);
}

Some general tips I can provide are:

  • Do not use a full black #000000 color, neither for text nor background
  • Use (slightly) different link and accent colors in dark mode. They can have a very different aesthetic on different backgrounds
  • Reducing saturation or opacity to make images look less aggressive

Achieving a smooth transition between dark and light mode

If you want a smooth transition between the themes, you can achieve that by adding a transition for background and text color to your CSS.

* {
    transition: background-color .33s, color .33s;
}
